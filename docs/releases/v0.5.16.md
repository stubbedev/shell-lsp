shell-lsp 0.5.16 makes large Nix workspaces far cheaper, answers faster between
requests, and fills the remaining gaps in Nix and in languages written from Nix.

## Faster and lighter

Measured with `cmd/nixparity`. Peak and idle are shell-lsp's own memory:

| Workspace | Peak, 0.5.15 | Peak, 0.5.16 | Idle, 0.5.15 | Idle, 0.5.16 | nixd peak |
|---|---|---|---|---|---|
| 89-file flake | 78 MiB | 93 MiB | 62 MiB | 65 MiB | 576 MiB |
| nixpkgs | 615 MiB | 142 MiB | 119 MiB | 87 MiB | 394 MiB |

The small flake uses more memory on purpose: the collector now runs at Go's
default pacing, which spends about 35% less CPU per keystroke on a large file.
`GOGC` still overrides it.

- Opening a Makefile or Dockerfile in a tree full of Nix no longer parses every
  Nix file: 1,685 MiB down to 40 MiB on nixpkgs, and definition from 1,450 ms to
  12 ms.
- On nixpkgs, definition p99 fell from 18-49 ms to 3-6 ms, and references p99
  from 11-20 ms to 2-5 ms.
- Caches are kept while you work. References at a relaxed typing pace went from
  a p90 of 7.6 ms to 0.36 ms, and reopening a closed file's project is immediate.
- `workspace/diagnostic` on nixpkgs takes half the time and about 40% less memory.

## Nix and embedded languages

- Two scripts in one file no longer share variables: definition, references,
  rename, hover and completion stay within the script.
- Justfiles, Makefiles and Dockerfiles written by a `.nix` string get fixes, hover,
  rename, completion and signature help at any depth. Refactorings reach Nix
  inside strings.
- `wrapProgram`, `makeWrapper`, `substituteInPlace` and other stdenv commands get
  hover, flags, completion and signature help. Awk and jq programs get completion
  and signature help.
- New refactorings: `with` to `let inherit`, and extract to a file. Type definition
  on an option goes to its `type`.
- `lib.extend` resolves from source.
- Formatting matches `nixfmt` 1.5.0 on all 44,765 `.nix` files in nixpkgs.

## Fixes

- Renaming a just, make or docker name inside Nix no longer gets a Nix attribute
  refusal.
- `wrapProgram` in a phase no longer hovers as "command not found", and hover no
  longer shows the internal `__nix__` stand-in.
- A fix that together removes all the shallowest lines of an indented string is
  withheld, since it would re-indent the rest.
- Updated the extension's `minimatch`, `follow-redirects` and `qs` for their
  security advisories.

## Known limits

- `pkgs.nerd-fonts.jetbrains-mono` and other generated attributes need
  `shellLsp.nix.evaluate`.
- Findings for `SC2034` and `SC2154` can still see a variable from another script
  in the same file. That can hide a finding, and never adds a false one.

## Install

Release binaries for Linux and Windows (amd64, arm64) and macOS (arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.5.16` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.5.16.vsix` below. Editor setup:
[docs/editors.md](https://github.com/stubbedev/shell-lsp/blob/main/docs/editors.md).
