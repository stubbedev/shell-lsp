shell-lsp 0.5.20 fixes two crashes the nightly fuzzing found on unfinished input.

## Fixes

- A `jq --arg name "` or `awk -v name="` whose quote is still open while you type
  no longer crashes the embedded-language support. The binding takes the rest of
  the line as its value.
- Formatting a Nix file such as `{ a, or` is refused with the syntax error instead
  of crashing. A bare `or` hid the real error at the same position.

## Install

Release binaries for Linux and Windows (amd64, arm64) and macOS (arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.5.20` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.5.20.vsix` below. Editor setup:
[the documentation](https://stubbedev.github.io/shell-lsp/editors/).
