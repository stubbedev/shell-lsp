shell-lsp 0.5.11 reads the shell around the cursor, in error hints, in lint
rules and in the files that embed shell from syntax trees and a shell lexer
instead of regular expressions over text. Contexts that text matching got
wrong now work, and several checks stop reporting text that only looked like
shell.

## Completion

- Every completion context comes from the syntax tree of the statement at the
  cursor: variables, expansion operators, subscripts, zsh flags and glob
  qualifiers, `[[` operands, case patterns and printf directives.
- Variables are offered in slice offsets, arithmetic subscripts and `let`, and
  no longer where an arithmetic operator goes.
- Redirection targets and the words of a `for` loop complete as paths.
- Contexts after a quoted word that spans lines, `$(` inside `$((`, expansion
  operators in here-documents and nested expansions, and quoted keys such as
  `${m["k` now complete.
- Printf directives are no longer offered inside `%(...)T`.

## Diagnostics

- The hints added to syntax errors, such as `elseif` or `]] -o`, come from a
  shell lexer: they no longer fire inside quotes or comments, and `} elsif`,
  `name+=((` and a stray word after `(...)` get theirs.
- SC2016 no longer reports single-quoted text that would not expand in double
  quotes either, such as `\$x`, an unclosed `${`, `$$x`, or `$q` in a sed
  program where `$` is the last line.
- SC2142 no longer reports aliases whose `$1` sits in a single-quoted awk
  program, is escaped, or belongs to a function the alias defines.
- SC2096 reads the shebang as `env` reads it: `env -vS` splits its argument,
  `--split-string` is reported, and other interpreters never split.
- Printf flags are read in any order, so `%0-5d` is a `d` conversion.
- In Makefiles, justfiles and other files that embed shell, `$((1<<2))` and a
  `<<` in a comment or quotes no longer start a here-document that swallows the
  following lines.

## Other fixes

- Bats results keep a test name starting with a dash, and only real TAP plan
  and test lines are read.
- Links in comments keep balanced parentheses such as
  `Bash_(Unix_shell)` and stop before `{`.
- Remove the quotes offers values with a comma, and no longer reserved words.

## Install

Release binaries for Linux, macOS and Windows (amd64, arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.5.11` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.5.11.vsix` below. Editor setup:
[docs/editors.md](https://github.com/stubbedev/shell-lsp/blob/main/docs/editors.md).
