shell-lsp 0.5.18 makes typing in large justfiles and Makefiles much faster, and
follows variables between the phases of a derivation. The documentation is now
[a site](https://stubbedev.github.io/shell-lsp/).

## Faster typing in recipes

| Keystroke | Before | After |
|---|---|---|
| justfile, 1,200 recipes | 100 ms | 26 ms |
| Makefile, 1,500 rules | 49 ms | 28 ms |

Most of the gain comes from removing quadratic lookups. The rest comes from checking
each recipe on its own and reusing the report of a recipe that did not change,
verified against a full recompute over a 400-edit replay in each language. Opening
a large file costs more, because nothing can be reused yet: a 1,500-rule Makefile
goes from 56 ms to 120 ms.

## Findings

- Recipes are checked alone, so a variable in one recipe no longer affects findings
  in another. Your justfiles and Makefiles may show new findings for this reason:
  `SC2034` for a variable only another recipe reads is now reported, since recipes
  run in separate shells.
- A `$` parameter in a just recipe is treated as unknown, so an unquoted `$target`
  now reports `SC2086`. It splits on spaces when just runs it.
- Variables stdenv reads, such as `dontPatchShebangs`, no longer report `SC2034` in
  derivation scripts.
- A recipe or script whose command is only `$(macro)` or `{{expression}}` may run
  anything, so it is no longer told a variable is unused or unassigned.

## Navigation and completion

- A variable set in `configurePhase` and read in `buildPhase` is followed by
  definition, references, rename, hover and completion.
- Definition on `/bin/jq` next to `${pkgs.jq}` goes to the package.
- The first key in a flake input set completes, as does `inherit (lib) x`.

## Fixes

- Hover, semantic tokens and pattern findings on a zsh `=~` regex no longer drift
  by a character when it is quoted, escaped or held in a variable.

## Install

Release binaries for Linux and Windows (amd64, arm64) and macOS (arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.5.18` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.5.18.vsix` below. Editor setup:
[the documentation](https://stubbedev.github.io/shell-lsp/editors/).
