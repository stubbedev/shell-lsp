shell-lsp 0.5.19 makes Make recipes more accurate, guards recipe findings against
regressions, and gives the documentation
[a new site](https://stubbedev.github.io/shell-lsp/).

## Make and just findings

Your Makefiles and justfiles may show different findings after this release.

- `$(Q)for ...`, `$(Q){`, `$(Q)x=1` and `$(Q)( ...` no longer give false findings.
  make strips the `@` after expanding, so these run as shell, and the macro is no
  longer read as part of the first word. Across the corpus this removes 15 false
  findings, and uncovers 7 true ones it was hiding.
- A macro that ends in `;` is read as ending the command before it, which removes
  a false `SC1010` on `fi`.
- An exported Make variable is treated as unknown, so an unquoted `$$TOKEN` reports
  `SC2086`: make splits it on spaces. `export` and `unexport` follow make's rules
  for which one wins, and `export X` with no assignment reaches the recipe.
- `x={{y}}` then `$x`, and `x=$(Y)` then `$$x`, report `SC2086`.

## Fixes

- Turning `shellLsp.nix.evaluate` off no longer lets a background warm-up start
  an evaluator again for a moment.
- Quoted zsh `=~` regexes are highlighted as regexes.

## Documentation

The documentation site is rebuilt on VitePress, with a landing page, search and
dark and light modes. Page URLs are unchanged.

## Regression guard

`lintcheck recipes` compares shell findings in just and Make recipes to a tracked
baseline in CI, and the Nix parity baselines are now tracked too.

## Known limits

- `$(Q)` separated from a command by a space can still give a false finding, since
  `$(X) {` could be a command with an argument.
- An `export` in an included Makefile does not reach the file that includes it.

## Install

Release binaries for Linux and Windows (amd64, arm64) and macOS (arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.5.19` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.5.19.vsix` below. Editor setup:
[the documentation](https://stubbedev.github.io/shell-lsp/editors/).
