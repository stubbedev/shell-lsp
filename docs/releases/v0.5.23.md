shell-lsp 0.5.23 takes shell options from the files a script sources, stops
Nix projects from relinking after an unchanged file is closed, fixes Nix
formatter layouts the nightly fuzzing found, and lets the test suite pass
where the temp dir cannot be watched.

## Fixes

- Options a sourced file turns on, with `setopt`, `set -o` or `shopt -s`, now
  count in the script that sources it from the `source` or `.` command on,
  also through nested sources. A script that sources a file running
  `setopt extendedglob` no longer gets SL2016 for `(#i)`, and one that turns
  on `pipe_fail` no longer gets SC2312. A source inside a subshell or `$(…)`
  leaves the rest of the script alone. Hover and semantic tokens read the same
  options. When bash reads an extended glob on the same line as the source that
  turns `extglob` on, SL2016 names that source command. Thanks to
  [@jczacharia](https://github.com/jczacharia) for the report and the fix.
  ([#89](https://github.com/stubbedev/shell-lsp/issues/89),
  [#90](https://github.com/stubbedev/shell-lsp/pull/90))
- Closing a Nix file without changing it no longer makes its project link
  again from scratch the next time it is read; that happened whenever the
  garbage collector ran in between.
  ([#91](https://github.com/stubbedev/shell-lsp/issues/91))
- The Nix formatter lays out a set-pattern lambda chained behind a named
  parameter, and a file whose first line is an empty comment, the same way on
  every pass.
- The tests that need a file watcher skip where inotify cannot watch every
  ancestor of the temp dir, as on Android (nix-on-droid), instead of failing
  the package build there.

## Install

Release binaries for Linux and Windows (amd64, arm64) and macOS (arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.5.23` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.5.23.vsix` below. Editor setup:
[the documentation](https://stubbedev.github.io/shell-lsp/editors/).
