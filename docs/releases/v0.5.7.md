shell-lsp 0.5.7 stops indexing files that git ignores. The workspace scan
behind workspace symbols, references, rename and the other cross-file
features read every shell script under the workspace, generated ones
included, and kept each one parsed in memory. In a Rust project with devenv,
1,700 generated scripts in `.devenv/` and `target/` took the server to
3.4 GB on the first workspace symbol request.

## Fixes

- The workspace scan, and the directories given to `shell-lsp check` and
  `shell-lsp fmt`, skip what git ignores: the `.gitignore` files from the
  repository's top down to each directory, and `.git/info/exclude`, in linked
  worktrees and submodules too. In the project above, the server now stays at
  17 MB. A file that is open in the editor, sourced by another script, or
  named on the command line is still read when it is ignored.

## Install

Release binaries for Linux, macOS and Windows (amd64, arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.5.7` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.5.7.vsix` below. Editor setup:
[docs/editors.md](https://github.com/stubbedev/shell-lsp/blob/main/docs/editors.md).
