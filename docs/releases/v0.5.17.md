shell-lsp 0.5.17 lints each script in a Nix file on its own, makes typing in
script-heavy files up to three times faster, and fixes range formatting that
could corrupt a file.

## Fixes

- Range formatting could break what it touched. A blank line in a `''` string
  split the edit, changing the string's indent and so its value, and partly
  reindented just recipes broke the same way. Edits could also anchor on the wrong
  identical line, such as `};` or `fi`, and lose code. Lines of a string or recipe
  now move together, even when that changes more lines than you selected. Checked
  against `nix-instantiate --parse` on 2,356 groups of edits from nixpkgs.
- "Extract to file" handled names with spaces, slashes or `..` wrongly, and could
  write outside the directory. It now also keeps meaning for `__curPos` and formats
  the new file.
- Builder commands hover as `sh`, not `nix`.

## Each script is linted alone

Scripts in one Nix file used to see each other's variables and options, which hid
findings and invented others. Each independent script is now its own unit. Spliced
strings stay one script, as do phases of one derivation and pieces of one option,
and sourced surfaces stay visible to all.

Across 44,765 nixpkgs files, findings go from 37,694 to 37,588: 154 wrong or
misplaced ones go away, and 48 true ones appear. Your own Nix files may show new
findings for this reason. Some variables stdenv reads, such as `dontPatchShebangs`,
still report `SC2034`.

## Faster typing

| Keystroke | Before | After |
|---|---|---|
| 700 scripts, editing outside them | 41 ms | 14 ms |
| 700 scripts, typing in one | 41 ms | 20.5 ms |
| Plain 5,000-line Nix file | 45.8 ms | 43 ms |

Findings for a script whose text did not change are reused, and verified against a
full recompute over a 600-edit replay. Memory rises slightly, to about 95 MiB peak
and 68 MiB idle on an 89-file flake.

## More answers

- `finalAttrs` works in every builder, including `buildRustPackage`,
  `buildPythonPackage` and `buildGoModule`.
- `x.` offers what the file reads through `x`.
- Flake input keys complete, such as `follows` and `url`.
- `pkgs.x` follows `aliases.nix`.

Comparing with nixd and nil on more random samples found these gaps. A few rows
remain where they answer and we don't. Those read so far are recorded by class in
[docs/corpus.md](https://github.com/stubbedev/shell-lsp/blob/main/docs/corpus.md).

## Install

Release binaries for Linux and Windows (amd64, arm64) and macOS (arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.5.17` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.5.17.vsix` below. Editor setup:
[docs/editors.md](https://github.com/stubbedev/shell-lsp/blob/main/docs/editors.md).
