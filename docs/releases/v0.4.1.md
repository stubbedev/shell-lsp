shell-lsp 0.4.1 fixes diagnostics in Neovim.

## Fixes

- Diagnostic tags are sent as an integer array. They went out as a base64
  string, so Neovim raised `bad argument #1 to 'ipairs'` whenever a file had
  a finding tagged deprecated or unnecessary, such as backtick command
  substitution.

## Install

Release binaries for Linux, macOS and Windows (amd64, arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.4.1` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.4.1.vsix` below. Editor setup:
[docs/editors.md](https://github.com/stubbedev/shell-lsp/blob/main/docs/editors.md).
