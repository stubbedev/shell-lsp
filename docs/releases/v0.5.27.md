shell-lsp 0.5.27 fixes bugs the fuzzers found in the Makefile analysis, the
sed and awk parsers and the Nix formatter.

## Fixes

- Makefiles:
  - A recipe shared by several targets, such as a static pattern rule over
    `$(OBJS)`, is checked for every one of its targets, not only the first.
    A variable that references itself through any of them is reported as
    make reports it, a variable only a later target defines is no longer
    called unknown, and go to definition and the "did you mean" fixes look
    in every target.
  - An expansion reached from two points that see different definitions is
    followed from both, so a recursive variable make rejects is no longer
    missed because a later line also reaches it.
  - Large Makefiles with many targets per rule are analysed faster; git's
    Makefile takes about half the time it did.
- sed and awk: a line with many unclosed `[` brackets or bracket elements
  such as `[:` is scanned once instead of once per bracket. Completion in
  such a line took seconds and could stall the server.
- Nix formatter: a set-pattern lambda after a named parameter and a blank
  line keeps its body on the colon line only while the pattern fits on one
  line, as nixfmt settles it, so formatting the output again no longer
  changes it.

## Install

Release binaries for Linux and Windows (amd64, arm64) and macOS (arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.5.27` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.5.27.vsix` below. Editor setup:
[the documentation](https://stubbedev.github.io/shell-lsp/editors/).
