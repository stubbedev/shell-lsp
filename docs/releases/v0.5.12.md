shell-lsp 0.5.12 finishes moving completion and the shell lexer onto the
syntax: the word a completion replaces ends where its node ends, and the
lexer behind syntax error hints reads extended globs and glob groups as each
shell does.

## Fixes

- Completing in the middle of a word replaces up to the end of the word as
  the shell reads it: `gr|ep$(date)` keeps the `$(date)`, and `gr|ep\ x`
  replaces the escaped space along with the rest of the word.
- Syntax error hints read `@(a|b)`, `+(x)` and `!(y)` in bash and ksh, zsh's
  glob groups and qualifiers such as `*.(c|h)(N)`, and ksh93's pattern groups
  such as `~(E)re` as part of their word instead of as a subshell.

## Install

Release binaries for Linux, macOS and Windows (amd64, arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.5.12` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.5.12.vsix` below. Editor setup:
[docs/editors.md](https://github.com/stubbedev/shell-lsp/blob/main/docs/editors.md).
