shell-lsp 0.5.14 fixes two crashes that the nightly fuzzers found on
malformed input.

## Fixes

- The linter no longer panics on a zsh word whose recovered parts overlap,
  such as `$A[0[0[0[0 .#000`, where the parameter expansion ends after the
  literal that follows it starts. Such a word is no longer read as a glob
  pattern.
- An unclosed here-document no longer gives a command a span past the end of
  the file. Recovery appends the missing delimiter so the parse can finish,
  and that line used to be indexed as a command of its own, as in `<<0(`
  followed by `#` and an unclosed `(`.

## Install

Release binaries for Linux and Windows (amd64, arm64) and macOS (arm64) with
`SHA256SUMS` are attached below. Alternatively
`go install github.com/stubbedev/shell-lsp@v0.5.14` or
`nix profile install github:stubbedev/shell-lsp`. For VS Code, install the
Shell LSP extension, or `shell-lsp-0.5.14.vsix` below. Editor setup:
[docs/editors.md](https://github.com/stubbedev/shell-lsp/blob/main/docs/editors.md).
